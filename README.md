# NeuroStream Studio

Настольное приложение для управления TikTok LIVE трансляциями: TikTok LIVE + AxelChat,
независимая озвучка (TTS), конструктор триггеров, управление IoT-устройствами и
алерты для OBS Studio через Browser Source.

Стек: **Electron + Node.js + Express + Socket.io + SQLite (better-sqlite3) + tiktok-live-connector**.

---

## 1. Требования

- **Node.js 20 или новее** (проверялось на Node 22) — https://nodejs.org
- **Windows 10/11** для итоговой сборки `.exe` (разработку и `npm run dev` можно запускать и на другой ОС,
  но production-сборка выполняется под Windows через `electron-builder --win`).
- Python и инструменты сборки C++ обычно не требуются — `better-sqlite3` устанавливается через
  готовый бинарник, а `electron-rebuild` (см. ниже) пересобирает его под ABI Electron автоматически.

## 2. Установка

```bash
npm install
```

Эта команда установит все зависимости и автоматически выполнит `electron-builder install-app-deps`
(хук `postinstall` в `package.json`), который пересобирает нативный модуль `better-sqlite3`
под версию Electron, указанную в `package.json`.

Если по какой-то причине автоматическая пересборка не сработала — выполните вручную:

```bash
npm run rebuild
```

## 3. Запуск в режиме разработки

```bash
npm run dev
```

Откроется главное окно панели управления. Встроенный сервер поднимается на локальном порту
(по умолчанию `47823`, при занятости — следующий свободный) и обслуживает:

- `http://127.0.0.1:<порт>/index.html` — панель управления (открывается автоматически)
- `http://127.0.0.1:<порт>/overlay.html` — страница для **OBS Browser Source** (добавьте её
  как источник "Браузер" в OBS; адрес также отображается во вкладке *Media Library*)
- `http://127.0.0.1:<порт>/tts-host.html` — служебная страница озвучки (открывается скрытым окном
  автоматически, вручную открывать не нужно)

## 4. Подключение к TikTok LIVE

1. Во вкладке **Dashboard** укажите `@uniqueId` стримера (без `@`).
2. Библиотека `tiktok-live-connector` v2 подписывает WebSocket-запросы через сервис
   **Euler Stream** (eulerstream.com). Без ключа доступен бесплатный общий лимит запросов —
   этого достаточно для тестирования, но при долгих стримах или частых переподключениях
   рекомендуется получить бесплатный/платный `signApiKey` на сайте Euler Stream и указать
   его в соответствующем поле — это снимает ограничение по лимиту.
3. Приложение автоматически переподключается при обрыве связи (экспоненциальная задержка
   3с → 6с → 12с … до 60с).

## 5. Подключение к AxelChat

[AxelChat](https://github.com/3dproger/AxelChat) — отдельное открытое приложение-агрегатор
чатов (Twitch, YouTube, VK и др.). NeuroStream Studio подключается к его локальному
WebSocket-серверу и озвучивает/обрабатывает сообщения независимо от TikTok-чата.

1. Установите и запустите AxelChat.
2. В настройках AxelChat включите **Settings → Developers → WebSocket server**
   (по умолчанию слушает `127.0.0.1:8356`).
3. Во вкладке **Dashboard** укажите хост/порт (по умолчанию уже подставлены `127.0.0.1:8356`)
   и нажмите «Подключиться».

## 6. Сборка `.exe` для Windows

```bash
npm run dist
```

Команда запускает `electron-builder --win nsis` и создаёт установщик в папке `release/`
(например, `release/NeuroStream Studio Setup 1.0.0.exe`). Сборку нужно выполнять на Windows
(или в CI на `windows-latest` — см. `.github/workflows/build-windows.yml`, который делает это
автоматически при пуше в репозиторий и публикует готовый `.exe` в разделе Releases).

Иконка приложения лежит в `build/icon.ico` — это временная заготовка (простой неоновый
монограммный логотип), замените её на свой файл при желании.

## 7. Структура проекта

```
src/
  main/            Electron main process (main.js, preload.js)
  server/
    db/            SQLite: схема (schema.sql), подключение (database.js), репозитории (repos.js)
    services/      Вся бизнес-логика: TikTok/AxelChat коннекторы, TTS-очередь, триггеры,
                    IoT, медиатека, фильтр мата, монитор ресурсов
    routes/api.js  REST API
    index.js       Сборка сервера: Express + Socket.io + все сервисы вместе
  renderer/
    index.html     Панель управления (6 вкладок)
    overlay.html   Страница для OBS Browser Source
    tts-host.html  Скрытая страница синтеза речи (Web Speech API)
    css/, js/      Стили (4 темы) и клиентская логика по вкладкам
build/             Ресурсы для electron-builder (icon.ico)
```

## 8. Известные ограничения / что можно улучшить дальше

- Иконка (`build/icon.ico`) — базовый placeholder, стоит заменить на финальный логотип.
- Синтез речи использует голоса, установленные в Windows (через Web Speech API Chromium).
  Для более естественных голосов в будущем можно добавить облачный TTS-провайдер
  (Azure/ElevenLabs) — архитектура `ttsQueue.js` уже это допускает.
- Сворачивание в системный трей не реализовано — сейчас закрытие окна завершает приложение.
- Drag-and-drop переупорядочивание действий триггера реализовано кнопками ↑/↓
  (без визуального перетаскивания мышью).
